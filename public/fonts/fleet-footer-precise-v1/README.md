# IssuePages footer fonts

Exact OFL-licensed local Geist, Geist Mono and Newsreader WOFF2 assets from the owner-selected Precise study. Source URLs, real axes, hashes and license filenames are in provenance.json. The three OFL files accompany their fonts. No subsetting or renaming of font binaries; Fleet family names are CSS aliases only. IssuePages serves them on the same origin under `/fonts/fleet-footer-precise-v1/`; no cross-origin access is needed. No Google Fonts request is made by the runtime.
